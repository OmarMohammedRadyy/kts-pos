# KTS POS — الدليل الشامل والمخطط العام للنظام (Master Blueprint)
## جمعية المعلمين الكويتية — نظام مبيعات وإدارة المكتبة والقرطاسية

---

### 1. نظرة عامة على المشروع (Project Identity & Purpose)
نظام **KTS POS** هو تطبيق متكامل لإدارة نقاط البيع (Point of Sale) وإدارة المخزون، الموردين، الأعضاء، الخصومات، الورديات، والتقارير المالية، مصمم ومخصص حصرياً لـ **جمعية المعلمين الكويتية — مكتبة القرطاسية**.

- **طبيعة النظام:** نظام هجين مكتبي/محلي (Local-First Desktop Web POS).
- **الهدف التشغيلي:** العمل بكفاءة وسرعة فائقة داخل نقطة البيع في المكتبة، مع دعم كامل للعمل دون اتصال بالإنترنت (Offline Capability)، والمسح الضوئي الفوري بالباركود، وتطبيق قواعد الخصم المعتمدة للأعضاء، وتقسيم الدفع، وطباعة الإيصالات الحرارية، وتصدير التقارير الرسمية إلى Excel.
- **اللغة والاتجاه:** لغة عربية متكاملة كواجهة أساسية بتصميم مؤسسي من اليمين إلى اليسار (RTL - Right to Left) وفق هوية جمعية المعلمين الكويتية الرسمية.

---

### 2. البنية التقنية (Technology Stack)
تم بناء النظام ليكون خفيفاً وسريعاً ومستقلاً عن أطر العمل المعقدة التي تثقل بيئات الكاشير:

| الطبقة (Layer) | التقنية المستخدمة | التبرير التقني |
| :--- | :--- | :--- |
| **قاعدة البيانات (Database)** | **SQLite (Node.js DatabaseSync)** | قاعدة بيانات محلية مدمجة فائقة السرعة، تعمل بنمط `WAL Mode` (Write-Ahead Logging) مع فهارس `B-Tree` على الباركود وSKU والمدني، قادرة على استيعاب 50,000+ صنف و100,000+ عضو وزمن استجابة < 3ms. |
| **الخادم الخلفي (Backend)** | **Node.js (Native) + Express.js** | خادم REST API محلي وسريع ومستقر، بدون تبعيات ثقيلة، يدعم التشفير الذاتي (PBKDF2 SHA512) ومعاملات ذرية (Atomic Transactions). |
| **الواجهة الأمامية (Frontend)** | **Vanilla HTML5 + Modern CSS + Vanilla JS** | لا يوجد React أو Vue أو أطر عمل تستهلك الذاكرة. كود جافاسكريبت أصلي وخفيف للغاية يعمل بسرعة 60FPS حتى على أجهزة نقاط البيع ذات المواصفات المحدودة. |
| **تصميم الواجهة (Styling)** | **Institutional Design System (Pure CSS)** | تصميم مؤسسي فخم بهوية كحلية ملكية (`#0f2238`) مع لمسات برتقالية دافئة (`#ea580c`) وتوافق RTL بنسبة 100% وخطوط Cairo & Noto Sans Arabic. |
| **مكتبات مساعدة (Utilities)** | **ExcelJS + Multer + Canvas (Fallback)** | لتصدير تقارير الإكسل الرسمية المنسقة، ورفع صور الأصناف والفئات محلياً، والمؤثرات الصوتية للكاشير عبر `Web Audio API`. |

### 4. الوحدات والوظائف الرئيسية للنظام (Core Modules & Capabilities)

1. **شاشة الكاشير السريعة (High-Speed POS Screen):**
   - ماسح الباركود السريع (Hardware Barcode Scanner Support) عبر اختصار `F2` واستماع الـ Enter.
   - كتالوج الأصناف والفئات البصري مع شريط الفئات الـ 5 والتنقل السلس.
   - بطاقة الصنف النشط، أزرار التعديل الكمي، ومؤثرات صوتية محاكية لأجهزة الكاشير (`Beep & Success Chime`).
   - سلة مبيعات فورية مع حساب الإجمالي، الخصم، والصافي بالدينار الكويتي (3 منازل عشرية: `0.000 د.ك`).
   - خيارات الدفع المتعددة: **نقداً (Cash)**، **K-Net (كي نت)**، و**تقسيم الدفع (Split Payment)** مع توزيع متساوٍ `50/50` وحساب متبادل فوري بين الحقول.
   - تعليق واسترجاع السلات (`Hold / Recall Cart`).
   - معاينة وطباعة الفاتورة الحرارية (80mm Thermal Receipt) بتصميم كويتي رسمي يشمل بيانات الجمعية ورقم الفاتورة ونوع الدفع.

2. **محرك الخصومات وإدارة العضوية (Membership & Discount Engine):**
   - التحقق من العضو برقم العضوية أو الرقم المدني أو الهاتف عبر اختصار `F8`.
   - إظهار بيانات العضو وفئته (معلم عامل، معلم متقاعد، عضو منتسب، إلخ).
   - **نافذة منبثقة احترافية لاختيار الخصم:** تمكين الكاشير من اختيار الخصم المعتمد المناسب للفاتورة أو البيع بدون خصم، مع عرض النسب المئوية (`%`) الصافية بدقة.
   - احتساب الخصومات على الأصناف المؤهلة فقط (`is_discountable`) مع حماية من الخصومات المزدوجة وتحديد السقف الأعلى للخصم.

3. **إدارة الورديات وجداول الدوام (Cashier Shifts & Schedules):**
   - بدء الوردية برصيد افتتاحي للعهدة (Opening Cash Drawer).
   - إغلاق الوردية بالعد الفعلي للنقد ومقارنته بالمبيعات النظامية لاستخراج العجز أو الفائض (Cash Discrepancy).
   - جدولة دوام الكاشيرات (صباحي / مسائي / كامل) وتحديد أيام العمل والراحة.
   - تقارير إقفال الوردية الفورية (`Z-Report`).

4. **لوحة الإدارة والمخزون (Admin & Inventory Management):**
   - لوحة تحكم بمؤشرات أداء رئيسية (مبيعات اليوم، عدد الفواتير، الأصناف منخفضة المخزون، الورديات المفتوحة).
   - إدارة المنتجات (إضافة، تعديل، حذف، تحديد الأسعار، الباركودات، الحد الأدنى للمخزون، والصور).
   - إدارة الفئات مع رفع الصور وتعيين الفئات الأب.
   - إدارة الموردين وربطهم بالأصناف.
   - إدارة سجل الأعضاء والفئات واستيرادهم.
   - إدارة قواعد الخصم مع الصلاحيات.
   - سجل التدقيق الشامل (`Audit Trail`).

5. **نظام التقارير والتصدير الرسمي إلى Excel (Official Reporting Engine):**
   - تقارير مبيعات تفصيلية ويومية وتجميعية حسب الكاشير، الفئة، وطريقة التحصيل.
   - تصدير رسمي إلى Excel بتنسيق فاخر عبر مكتبة `ExcelJS` بهوية جمعية المعلمين (ألوان ترويسة كحلية، حدود هندسية، محاذاة RTL، وحساب المعادلات التلقائية).

6. **إدارة الأمان والصلاحيات (Role-Based Access Control):**
   - أدوار محددة مسبقاً: **مدير النظام الرئيسي (Admin)**، **مشرف الفرع (Supervisor)**، و**كاشير (Cashier)**.
   - تشفير كلمات المرور باستخدام Salt ثابت ودالة `PBKDF2 SHA-512` بعدد 10,000 دورة.
   - حماية المسارات الحساسة بالتحقق من الصلاحيات وتتبع عنوان IP والمستخدم في سجل التدقيق.
